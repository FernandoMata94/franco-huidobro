AMI Automation

R&D and field project: DigiFex® field excitation system upgrades (CEMEX)

Led the control firmware architecture updates for an across-the-line synchronous machine excitation drive, responsible for starting sequences and PF/VAR regulation. Engineered two major updates:

Digital twin integration:Programmed a mathematical-model-based digital twin of the synchronous machine, enabling hardware-free simulations of control loops, logic, I/O, and protections to accelerate firmware validation and facilitate technical demonstrations.

Machine learning fault detection: Programmed a Support Vector Machine (SVM) algorithm to detect thyristor misfiring. Trained offline via MATLAB/Simulink, the model analyzes rectified volt age to identify firing failures, preventing AC-side unbalances.
